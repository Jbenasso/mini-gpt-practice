A tiny GPT-like model built from scratch in PyTorch.  
Trains on character-level text and generates new sequences.  
Great for learning the fundamentals of transformers!

## Features
- Character-level tokenization
- Transformer encoder layers
- From-scratch training loop
- Text generation

## Quickstart
```bash
git clone https://github.com/jbenasso/mini-gpt-practice.git
cd mini-gpt-clone
pip install -r requirements.txt
python main.py
